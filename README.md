# Monte Carlo Code for Institutional Asymmetry

This folder contains the cleaned Monte Carlo notebooks for *Institutional Asymmetry, Endogenous Fragility, and Economic Growth*. The notebooks reproduce the numerical exercises reported in the paper and the online appendix.

The notebooks are self-contained. They do not require Google Colab, Google Drive, OneDrive, or any project-specific absolute path. Each notebook saves its outputs in the directory from which it is run.

## Files

| Notebook | Numerical block | Main purpose |
|---|---|---|
| `mc_block1_micro_drag_pricing_spillovers.ipynb` | Online Appendix B.1 | Micro-to-drag diagnostics, fiscal feasibility, pricing reoptimization, spillover diagnostics |
| `mc_block2_threshold_dynamics.ipynb` | Online Appendix B.2 | Finite-horizon dynamic realization of static threshold geometry |
| `mc_block3_intervention_hysteresis.ipynb` | Online Appendix B.3 | Conditional bistable-domain hysteresis, stimulus response, and repeated-reform escape |

## Requirements

Use Python 3.9 or later. Install the required packages with:

```bash
pip install numpy pandas matplotlib scipy notebook
```

`scipy` is required by the intervention-hysteresis notebook. The other notebooks use `numpy`, `pandas`, and `matplotlib`.

## Running the Notebooks

Open Jupyter from this folder:

```bash
jupyter notebook
```

Then open and run any of the three notebooks. They can be run independently.

Each notebook creates a timestamped output folder in the current working directory:

```text
<MC_NAME>_<YYMMDD_HHMM>/
```

For example, running `mc_block3_intervention_hysteresis.ipynb` creates a folder such as:

```text
mc_block3_intervention_hysteresis_260711_1230/
```

All CSV files, configuration dumps, and figures generated by that run are saved inside the timestamped folder. The notebooks intentionally use:

```python
BASE_OUT_DIR = os.getcwd()
OUT_DIR = os.path.join(BASE_OUT_DIR, f"{MC_NAME}_{RUN_TS}")
```

so outputs are written wherever the notebook is executed.

## Random Seeds

The notebooks use fixed random seeds:

| Notebook | Seed |
|---|---:|
| `mc_block1_micro_drag_pricing_spillovers.ipynb` | `20260609` |
| `mc_block2_threshold_dynamics.ipynb` | `20260212` |
| `mc_block3_intervention_hysteresis.ipynb` | `20260312` |

Changing the seeds or sample sizes changes the numerical outputs.

## Output Summary

`mc_block1_micro_drag_pricing_spillovers.ipynb` writes summary CSV files for domain diagnostics, fiscal stress tests, positive-root corridors, extended-wedge diagnostics, pricing reoptimization, spillovers, overlap matrices, standardized distances, and a dynamics figure.

`mc_block2_threshold_dynamics.ipynb` writes CSV files for admissibility, audit diagnostics, trajectories, country-block summaries, treatment-block bins, plot files, and a `config_dump.json`.

`mc_block3_intervention_hysteresis.ipynb` writes CSV files for candidate audits, the accepted bistable pool, threshold-location summaries, regime summaries, hysteresis-margin profiles, stimulus attenuation, repeated-reform escape grids, figures, and a `config_dump.json`.

## Runtime Notes

The full runs are computationally nontrivial. Approximate runtimes depend on hardware and package versions.

| Notebook | Expected scale |
|---|---|
| Block 1 | Moderate |
| Block 2 | Long finite-horizon simulation |
| Block 3 | Long conditional simulation and policy grid |

For a quick test, reduce the sample-size parameters near the top of each notebook. Test runs will not reproduce the paper's reported values.

## Troubleshooting

If a package is missing, install the requirements again:

```bash
pip install numpy pandas matplotlib scipy notebook
```

If outputs are not where expected, check the folder from which Jupyter was launched. The notebooks save outputs to the current working directory, not to a fixed project path.

If a run is interrupted, remove the incomplete timestamped output folder or rerun the notebook to create a new timestamped folder.
